# 照片转拼豆图纸 · 纯前端 MVP

上传一张照片，选网格尺寸和颜色数，在浏览器里生成可以照着拼的拼豆图纸：每格色号/序号、四边行列号、图例（色号 / 名称 / HEX / 颗数 / 占比），支持导出高清 PNG 和打印 / 另存为 PDF（A4 自动分页）。

**图片只在本机浏览器处理，不上传任何服务器**；不登录、不支付、不调用任何 API，零构建、零第三方库，离线也能用。

## 功能

1. **上传**：点击或拖拽，支持 JPG / PNG / WEBP，左侧显示原图预览和尺寸。
2. **网格尺寸**：预设 29×29、50×50，自定义宽×高（10–200），一键「按原图比例」算高度；「裁剪填满」（居中裁切）或「完整入画（留边）」（留边部分为空格不拼）。
3. **颜色**：色板可切 MARD 221 / Perler；颜色数上限 8 / 16 / 24 / 32 / 48 / 不限。默认排除夜光、珠光、荧光、透明等特殊豆，可勾选加入。
4. **去杂点**：关 / 轻度（默认）/ 较强。孤立的单格、以及和周围多数格颜色只差一点的格子会并到邻近颜色，减少「麻点」。
5. **背景**：透明像素可选「留空（不拼）」或「当作白色」；可选「去除与边缘相连的背景」（从边缘按容差泛洪，背景格留空）。留空格画成带小圆点的白格，不计入颗数。
6. **图纸显示**：「只看颜色 / 颜色+编号」切换；格内标色号（如 A23）或序号（1、2、3…）；字的颜色按底色深浅自动选黑或白；每 5 格一条中线、每 10 格一条粗线，四边都有行列号；可以缩放、总览、双指缩放。点图例里某一行会高亮这个颜色的所有格子（拼的时候按颜色找位置用）。
7. **单格编辑**：点一格就选中它（再点同一格、点图纸空白、Esc 或「取消选择」都会退出）。可以输入色号、从色板下拉、点当前用色色块，或点图例的一行来改这一格；「设为留空」或 Delete / Backspace 把格子清空。颗数、占比和合计马上重算。打印时不带选中框。
8. **29×29 拼豆板**：默认画出橙色虚线和每块左上角的板号，并列出每一块的行、列、覆盖范围。宽或高不是 29 的倍数时，边上的块标成「边缘余量」。打印分页可以选「按拼豆板」，每块一页（放不下就退回自动分页，分界线仍在）。
9. **人像优化**：一键改成 16 色、较强去杂点，并打开「去除与边缘相连的背景」（容差 16）。这是边缘泛洪留空，不是 AI 抠图。针对灰背景上的麻点。
10. **图例**：色块、序号、色号、中文名（MARD）/ 英文名（Perler）、HEX、颗数、占比，合计颗数。正在改格子时，点图例的一行会改当前格，而不是高亮。
11. **导出 PNG**：标题 + 整张图纸 + 图例 + 出处页脚。开着分板提示时，PNG 上也有橙色分界。
12. **打印 / 存为 PDF**：用浏览器自带打印，在打印对话框里选「另存为 PDF」。A4 方向、每格尺寸、分页方式（自动 / 按拼豆板）可以选；放不下一页时自动分页，每页都有绝对行列号、本页范围和色号小图例，最后附完整用料清单页。打印时请选「实际大小 / 100%」。手机上主要按钮和输入框按大约 44px / 16px 排，避免点不准和聚焦时页面被放大。

## 算法简介

1. 按网格把图片画到 (宽×S)×(高×S) 的离屏画布（S 在 2–8 之间，按网格大小自动定），每格对 S×S 像素做带透明度权重的平均，相当于轻度平滑。
2. 在 CIE Lab 色彩空间里做匹配（亮度权重 0.9）。
3. 限色：在 Lab 里做 k-means（k-means++ 初始化，用固定种子，结果可复现），把每个簇中心吸附到最近的色板颜色，再细化两轮；去重后不够 K 个，就用全色板映射里用量最多的颜色补齐。
4. 每格映射到选中颜色里最近的一个，然后去杂点，最后按颗数从多到少编序号。

## 已知限制

- **色值不是官方值**：HEX 是第三方屏幕参考值，图上颜色和实物会有偏差。
- **人像效果取决于原图**：背景复杂或光线偏灰的照片，相近灰色会成片交替出现。「人像优化」会把颜色收到 16 色、加强去杂点，并用边缘泛洪去掉和边缘相连的背景。主体和背景颜色接近时仍可能误删，可以再调容差，或用单格编辑改回来。
- 「颜色数上限」是**上限**：如果原图映射到色板后本来就用不到这么多颜色，实际颜色会更少（比如 50×50 的测试图，不限色时也只用到 27 色）。
- 单页打印 50×50 时每格约 3.7 mm，三位色号的字比较小（约 4–5pt）。要看得更清楚，可以把「打印格子」选 5 mm 或 6 mm（会分成多页），或者把格内编号改成「序号」。
- 打印分页的页数是按 A4 和 8 mm 页边距估算的。如果打印对话框里改了缩放或边距，可能会多出页。
- 目前只支持 5mm 中豆色板，没有 2.6mm 迷你豆、Hama、Artkal；没有保存/分享工程文件。分板提示按 29×29 一块计算。
- 「去除背景」只是从边缘按颜色容差泛洪，不是 AI 抠图。主体和背景颜色接近时可能误删，需要调容差。
- 桌面 Chrome、桌面 Firefox，以及 Chrome 的 390×844 / 360×700 手机视口已用 Playwright 实测。**Safari 和真机未验证。** 打印对话框本身没有点过，分页是用页面生成的打印 DOM 再栅格化检查的。
- 图片在本机解码；超大图（比如 1 亿像素以上）可能受浏览器内存限制。
